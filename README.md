# Blinkit Sales Analytics Dashboard

## Project Overview

This project is an interactive sales analytics dashboard built using Microsoft Power BI. The dashboard provides an overview of Blinkit sales performance and allows users to analyze sales across different outlet types, outlet sizes, locations, item categories, and fat content.

## Dashboard Preview

[Blinkit Sales Analytics Dashboard](blinkit-dashboard.png)

## Tools & Technologies

- Microsoft Power BI
- Power Query
- DAX
- Microsoft Excel

## Dataset

The project uses a Blinkit sales dataset.

Basic data cleaning and preparation were performed using Power Query before creating the dashboard.

## Key KPIs

- **Total Sales:** 1.20M
- **Average Sales:** 141
- **Number of Items:** 9K
- **Average Rating:** 3.92

## Dashboard Features

The dashboard provides analysis of:

- Sales by outlet type
- Sales by outlet size
- Sales by outlet location tier
- Sales by item type
- Sales by fat content
- Outlet establishment trends
- Item-level sales performance
- Average ratings

## Interactive Filters

Users can filter the dashboard based on:

- Outlet Location Type
- Outlet Size
- Item Type

## DAX & Data Preparation

Basic data cleaning and transformation were performed using Power Query.

DAX measures were created to calculate key metrics such as total sales, average sales, number of items, and other dashboard metrics.
